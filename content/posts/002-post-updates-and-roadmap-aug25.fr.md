## Réseau
Pour travailler sur mon blog et mes autres projets personnels, j’utilise différents ordinateurs selon le moment et le lieu : dans le train, à mon bureau à la maison ou dans le salon tard le soir.
Je peux synchroniser mon code avec Git, mais les différences entre les environnements de développement de chaque appareil posent un vrai problème.

Pour le résoudre, j’envisage d’installer une machine virtuelle hébergée localement sur un serveur, qui servirait d’environnement de développement dédié.
Un obstacle possible : rendre cette machine accessible depuis l’extérieur de mon réseau domestique sans exposer directement de ports.
Je pense qu’un reverse proxy pourrait être la solution, mais je dois encore explorer la meilleure configuration.
